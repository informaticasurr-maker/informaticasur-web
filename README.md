# Informática Sur - Sitio Web Comercial

Landing page moderna y optimizada desarrollada a partir de la presencia en redes sociales por `04-social-web-builder`.

## 🚀 Despliegue en Vercel vía GitHub
Este repositorio está preparado para la cuenta `informaticasurr@gmail.com`.

### Pasos para publicar:
1. Crear el repositorio en tu cuenta de GitHub: `https://github.com/new`
2. Enlazar y subir este proyecto:
```bash
git remote add origin https://github.com/informaticasurr/informatica_sur-web.git
git branch -M main
git push -u origin main
```
3. Vercel detectará el nuevo repositorio automáticamente y desplegará la web en `https://informatica_sur-web.vercel.app` en menos de 30 segundos.
